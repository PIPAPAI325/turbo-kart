## 项目介绍

一款基于 **Three.js** 的 3D 卡丁车竞速网页游戏，玩法参考《马里奥赛车》。浏览器打开即可与 AI 对手同场竞速，采用实时物理模拟：加速、刹车/倒车、转弯惯性、漂移、护栏碰撞掉速均符合真实驾驶直觉，赛车不会穿墙。画面为白天晴朗、蓝天白云的明亮卡通风格。

### 主要特性

- **真实赛车物理**：速度、重心、轮胎抓地与惯性模拟，漂移集气，漂移 1.2 秒以上松开可触发迷你涡轮加速
- **3 张可选赛道**：阳光海湾、霓虹都市、云端山道，车道布局各异
- **3 档 AI 难度**：简单 / 普通 / 困难，困难 AI 经过标定，圈速接近玩家极限
- **8 名车手**：不同配色的 AI 对手，3 圈定胜负
- **3D 晴朗场景**：蓝天、体积云、阳光与动态阴影
- **音效系统**：引擎、漂移、碰撞等实时音效
- **零依赖运行**：单文件构建，任何静态托管均可直接部署

### 操作方式

| 按键 | 功能 |
|---|---|
| W / ↑ | 加速 |
| S / ↓ | 刹车 · 倒车 |
| A D / ← → | 转向 |
| Shift | 漂移（集气加速） |
| Esc | 暂停 |

移动端打开页面时会显示触屏方向键与漂移按钮。

### 技术栈

- 原生 JavaScript（ES Modules）+ Three.js（WebGL 渲染）
- 无构建框架；`tools/build_single.py` 将全部模块与依赖内联打包为单个 `index.html`
- `tools/sim/` 内为无头仿真校验工具（赛道几何、AI 与漂移手感验证）

### 本地运行

直接用静态服务器打开根目录 `index.html` 即可（ES Modules 不支持 `file://` 直接打开）：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

生成单文件部署版本（输出到 `dist/index.html`）：

```bash
python tools/build_single.py
```

### 目录结构

```
src/            游戏源码（物理、AI、赛道数据、音频、场景、主逻辑）
vendor/         Three.js 及插件
tools/          打包脚本与仿真校验工具
deploy-site/    单文件构建产物，用于线上部署
index.html      开发版页面
```
